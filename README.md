## 🧰 Мои проекты

### 🧾 [Автоматизация учёта расходов](https://github.com/yuris133/expense-automation)

Готовая система для учёта расходов семьи или команды. Фотографируешь кассовый чек в Telegram — дальше всё делает Python: конвейер читает QR-код с чека, получает позиции товара через API ФНС, раскладывает их по статьям бюджета и собирает свежие отчёты — Excel и HTML-дашборд. Если QR не читается — в ход идут PDF-парсер и OCR. Дубликаты отсекаются автоматически, а расход без чека добавляется простым сообщением: `500 обед при встрече`.

Собран с нуля: бот, конвейер обработки, справочник статей, инструкция по установке и развёртыванию на облаке.

`Python` `Telegram-бот` `OCR (Tesseract)` `QR-коды / API ФНС` `Excel-отчёты` `HTML-дашборд`

### 📋 [Дайджест вакансий](https://github.com/yuris133/job-vacancy-hh-digest)

Конвейер, который раз в неделю вручную собирает свежие вакансии по заданному профилю кандидата: поиск за последние 7 дней, проверка каждой карточки на активность (без «мёртвых» ссылок из кэша), ранжирование по совпадению, ведение сводной таблицы markdown+CSV и отправка топ-5 в Telegram-бот. Готовый пакет для других пользователей: README с установкой за 10 минут, скилл для Claude Code и шаблоны таблицы, дайджеста и сопроводительного письма.

`Claude Code skill` `hh.ru` `Telegram-бот` `методология поиска работы`
